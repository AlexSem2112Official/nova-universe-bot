# NOVA UNIVERSE — Telegram-бот

Запуск (Python 3.10+):

    pip install -r requirements.txt
    cp .env.example .env     # впишите BOT_TOKEN
    python bot.py

Хостинг: VPS, Railway, Render, Fly.io (процесс должен работать постоянно; Netlify не подходит).
Данные лежат в `DATA_DIR` (по умолчанию `data/`): БД и ключ шифрования. Подключите постоянный диск и не коммитьте папку.

## Возможности
- OpenRouter по умолчанию + 17 встроенных провайдеров, свой ключ у каждого пользователя, свои OpenAI-совместимые провайдеры.
- **Сессии**: у каждой своя история, бот помнит весь разговор сессии (до `HISTORY_CHARS` символов). Старая история при обновлении переносится в первую сессию.
- **Картинки и стикеры**: фото, изображения-файлы и стикеры уходят модели как картинки (vision). Модели с поддержкой помечены 👁 в /models. Для анимированных стикеров берётся превью. Последняя картинка сессии помнится для уточняющих вопросов. Если модель без vision, стикер всё равно понимается по эмодзи.
- Режимы, память, навыки, свой системный промпт, temperature, текстовые файлы, потоковый ответ.

## Бесплатный Render (Web Service)
Ноутбук `NOVA_Bot_Deploy.ipynb` с `MODE = "free"` разворачивает бота как бесплатный Web Service:
- **Будильник №1** — бот сам пингует свой `/health` каждые 4 минуты (Render усыпляет сервис после 15 минут без входящего трафика).
- **Будильник №2** — GitHub Actions пингует `/health` каждые 5 минут (`.github/workflows/keepalive.yml`).
- **Будильник №3** — последняя ячейка ноутбука пингует из Colab, пока открыта вкладка.
- **Бэкап БД** — раз в 5 минут (если база изменилась) и при остановке зашифрованный снимок уходит в приватный репозиторий `<repo>-backup`; при старте бот восстанавливает его. Файлы на free-диске иначе стираются при каждом рестарте.
